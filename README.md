# مهامي اليومية — نسخة مستقلة للآيفون v14

تطبيق مهام عربي RTL يعمل كتطبيق PWA على الآيفون ومن دون خدمات خارجية.

## ما تغير في v14

- إزالة OneSignal وCloudflare Worker بالكامل.
- لا توجد مفاتيح API أو حسابات أو خوادم خارجية.
- تصدير المهمة أو جميع المهام إلى تقويم الآيفون بصيغة iCalendar (`.ics`).
- التنبيه والتكرار يعملان من خلال تقويم الجهاز بعد تأكيد المستخدم للإضافة.
- فصل المهام الحالية عن المهام المكتملة.
- قائمة جانبية عربية من اليمين وزر إضافة من اليمين.
- إصلاح التعديل بحيث يحافظ على معرف المهمة ولا يلغي أي تنبيه بمجرد فتح النموذج.
- إصلاح نسخ المهام والتكرار الشهري وزر الساعة 8 مساءً.
- منع تكرار الموعد القادم للمهام الدورية.
- استيراد آمن للنسخ الاحتياطية مع التحقق من البيانات وإعادة إنشاء المعرفات.
- دعم العمل دون إنترنت وتحديث التطبيق عبر Service Worker مستقل.
- استخدام مسارات نسبية، لذلك يمكن نقل المشروع أو تغيير اسم المستودع دون تعديل المسارات.

## تثبيت التطبيق على الآيفون

1. افتح رابط GitHub Pages في Safari.
2. اضغط زر المشاركة.
3. اختر **إضافة إلى الشاشة الرئيسية**.
4. افتح التطبيق من الأيقونة الجديدة.

## إضافة تنبيه إلى تقويم الآيفون

1. أنشئ مهمة وحدد التاريخ والوقت والتنبيه والتكرار.
2. افتح خيارات المهمة واضغط **إضافة للتقويم**.
3. افتح ملف `.ics` وأكد إضافته إلى تقويم الآيفون.

تطبيقات الويب لا تستطيع إنشاء تنبيه iOS محلي مضمون وهي مغلقة دون خادم Push؛ لذلك تستخدم هذه النسخة تقويم الآيفون كحل مستقل وموثوق.
